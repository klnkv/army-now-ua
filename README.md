# ARMY NOW UA

Радіонет, екіпіровка, twin-stick фронт, FPV-виліт.

**Репозиторій:** https://github.com/klnkv/army-now-ua

## Папки

| Шлях | Що це |
|---|---|
| `front/` | Основна гра: штаб, екіпіровка, карти БЗВП, Фронт, FPV |
| `fpv/` | Камікадзе FPV 15 с (окрема місія, той самий код) |

## Front

Точка входу: `front/src/components/army-app.tsx`

- Реєстрація / екіпіровка / рід військ. Старт **без екіпіровки**.
- «Як потратив» — лише мітка профілю, не малює слоти.
- 12 секторів БЗВП (Полігон, Траншея, НП, Танкодром, Лісосмуга, Стрілецький рубіж, Вогнева позиція, Узбережжя, Зона БПЛА, Вузол зв'язку, Медпункт, Рубіж ППО).
- Фронт: twin-stick, top-down ґрунт сектора.
- Повітря / БПЛА: небо, без будинків і машин, бій проти дронів. ППО б'є літаки й дрони з землі.
- FPV: 600 очок на фронті = один 15-секундний виліт.
- Рація PTT, 3 секунди.
- Без герба в UI.

Інтеграція: `front/GROK-INTEGRATE.md`

## FPV

Точка входу: `fpv/src/components/game-app.tsx` (у збірці — `front/src/fpv/game-app.tsx`)

Інтеграція: `fpv/GROK-INTEGRATE.md`
